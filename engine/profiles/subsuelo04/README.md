# Perfil visual PS2 — Subsuelo04

Las texturas de `assets/textures/` provienen del proyecto [Subsuelo04](https://github.com/JoaquinGasperetti/subsuelo04) de HK Entertainment. El exportador PS2 las incluye como materiales base para pisos, techos, paredes de concreto y óxido, zonas rituales, puertas y rejas.

Los proyectos pueden reemplazar cualquiera de estas texturas poniendo un archivo con el mismo nombre en `assets/textures/`.
